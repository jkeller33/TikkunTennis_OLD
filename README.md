# Maya Keller: Free Tennis Lessons

The website for Maya Keller's volunteer tennis program.

## Before you publish
Open `index.html` in a text editor (like VS Code), search for `YOUR-EMAIL@example.com`, and replace it with a parent's email address.

## How to put this site on GitHub Pages
1. Sign in at github.com and click **New repository**. Give it a name like `maya-tennis` and make it **Public**.
2. On the new repository page, click **uploading an existing file**.
3. Drag in `index.html`, `README.md`, and the whole `images` folder. Then click **Commit changes**.
4. Go to **Settings → Pages**. Under "Branch," choose `main` and `/ (root)`, then click **Save**.
5. After a minute or two, the site will be live at `https://YOUR-USERNAME.github.io/maya-tennis/`.

## Updating later
- To change text, open `index.html` on GitHub, click the pencil icon, edit it, and commit.
- To add a photo, upload it into the `images` folder, then add an `<img src="images/your-photo.jpg">` line where you want it to appear.
